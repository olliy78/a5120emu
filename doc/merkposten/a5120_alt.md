# Frühe A5120 (Ausführungen Alt/Kmbg) + BCU 880 — Merkposten

Der A5120 „5¼″ alt“ und „Kassette“ als **Ausführung** derselben Klasse `A5120Machine`
(`Config::ausfuehrung` = `Neu` Vorgabe | `Alt` | `Kmbg`; `Acht` lehnt der Konstruktor ab, EM nur bei
`Neu`).  Karten `core/cards/k7023/`, `k3525/`, Tastatur `core/peripherals/k7636/`, Anschluss
`UBusGeraet` an der K2526.  Entwurf `doc/design/30_a5120_fruehe_varianten.md`, Stand/Karten
`doc/design/32_...`, Abschriften `doc/a5120_alt/{laderom,k7023,k7636,k5120,bcu}.md`.
C-ABI `k1520_create_a5120_ausfuehrung`/`k1520_a5120_ausfuehrung` (+ `k1520_create_a5120_konfig` mit Lade-ROM/Tastatur), Python
`K1520Emulator(ausfuehrung="alt"|"kmbg", laderom=…, tastatur=…)` bzw. `machine="a5120-alt"|"a5120-kmbg"`, Modell `a5120-bcu` im `a5120emu`, Werkzeuge
`boot_trace`/`k1520dbg --ausfuehrung neu|alt|kmbg --laufwerke … --laderom v09_2|v09_1|v06 --tastatur …`.
